# Healthcare Appointment System — Manual Testing

## Project Overview
This project documents manual testing performed on a healthcare appointment web application. The goal was to verify appointment booking, input validation, appointment management, and theme usability.

## Application Under Test
- **Application:** Healthcare Appointment System
- **Live Demo:** https://healthcare-appointment-app-three.vercel.app/
- **Testing Type:** Manual, Functional, Regression, and UI Testing

## Testing Tools
- **Jira:** Defect tracking and bug reporting
- **Chrome DevTools:** UI and browser debugging
- **Excel:** Test case documentation

## Test Coverage
- Valid and invalid appointment booking
- Required-field and patient-name validation
- Appointment deletion
- Data persistence after page refresh
- Duplicate appointment booking
- Dark-mode text readability and contrast

## Test Results

| Metric | Result |
|---|---:|
| Total test cases | 8 |
| Passed | 5 |
| Failed | 3 |

## Repository Contents
- `test-cases.md` — Test scenarios, expected results, actual results, and statuses.
- `bug-reports.md` — Documented defects with reproduction steps, expected behavior, and actual behavior.

## Key Findings
Testing identified a duplicate-booking issue and two dark-mode readability issues. The failed cases are documented for further investigation and verification.

## Disclaimer
This is a personal QA practice project based on testing a web application. The results represent observed behavior during testing and do not imply professional QA employment experience.
